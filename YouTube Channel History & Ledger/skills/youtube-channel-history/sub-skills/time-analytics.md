# Sub-Skill: Time & Cadence Analytics

## Overview
Optimizing YouTube algorithm distribution requires tracking upload cadence, production turnaround velocity, and scheduling videos during audience peak active hours.

## Key Metrics Tracked
1. **Production Turnaround Velocity**:
   - Elapsed time from prompt formulation -> video generation -> SEO synthesis -> queue injection -> live publishing.
2. **Shorts Pacing Analytics**:
   - Target duration: 24.0 seconds (optimal for 85%+ completion rates on YouTube Shorts).
   - Hook duration: 0.0 to 2.0s.
3. **Upload Cadence & Consistency**:
   - Weekly target: 3 Shorts per week.
   - Recommended posting days: Tuesday, Thursday, Saturday.
   - Peak viewer time slots:
     - 14:00 EST (US East Coast)
     - 18:00 UTC (European Prime)
     - 23:00 PKT (Local Production Hub)
4. **Cadence Health Score (0-100)**:
   - Evaluates whether the channel is maintaining consistent cadence or if an upload is overdue.
