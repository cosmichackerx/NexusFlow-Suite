# YouTube With Antigravity — Quick Reference & Operations Guide

Welcome to **YouTube With Antigravity**, the ultimate creator engineering and autonomous publishing framework for Google Antigravity.

|---------|-----------|---------|

| `/youtube script` | `sub-skills/script.md` | Retention-engineered scripts with hook, setup, body blocks, pattern interrupts, and CTA. |
| `/youtube hook` | `sub-skills/hook.md` | 5 hook variants (Shock, Agitation, Story, Curiosity, Social Proof) with drop-off risk ratings. |

| `/youtube calendar` | `sub-skills/calendar.md` | Monthly content calendar with Shorts supplements and seasonal RPM timing. |
| `/youtube shorts` | `sub-skills/shorts.md` | High-retention Shorts production package with visual change markers. |

## CLI Quick Reference

```bash
# Check status across NexusFlow, YouTube Uploader, and Antigravity
node cli.js status

# Scan NexusFlow videos
node cli.js scan

# Probe video duration, resolution, and Shorts qualification
node cli.js probe "path/to/video.mp4"

# Generate high-retention metadata
node cli.js metadata "path/to/video.mp4"

# Add to YouTube upload queue
node cli.js queue "path/to/video.mp4"

# Run end-to-end autonomous pipeline
node cli.js pipeline
```
