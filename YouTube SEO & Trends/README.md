# YouTube SEO With Antigravity

> **The Native YouTube SEO, Channel Management, Viral Trend Discovery, and Automated Publishing Suite for Google Antigravity & NexusFlow**

`YouTube SEO With Antigravity` provides an end-to-end algorithmic intelligence system engineered to place your YouTube channel (**Bones of Empires**) at the top of YouTube Search, Suggested Browse, and the Shorts Feed.

---

## Key Capabilities

1. **Channel Management & Health**:
   - Live tracking of YouTube Studio authentication for `@BonesOfEmpires`.
   - Content pillars, mascot lore (`Marrow`), and competitive positioning vs top channels (*Voices of the Past*, *History Bypass*, *Fall of Civilizations*).

2. **Full Algorithmic SEO Engine**:
   - **4 Distinct Title Variants**: Browse Hook, Search SERP, Hybrid (+20-30% CTR), and Mobile Ultra-Shorts.
   - **Structured 5,000-Character Description**: Above-the-fold hook, narrative lore, dialogue quotes, timestamps, engagement trigger question, CTAs, and Schema.org VideoObject JSON-LD.
   - **Tags Matrix**: Strictly under 500 characters, covering brand, broad history, mid-tail topics, and long-tail query phrases.
   - **Hashtag Matrix**: 3 primary display hashtags + 10 extended indexing hashtags.

3. **0-100 Algorithmic SEO Quality Audit**:
   - Automatic scorecard auditing Title CTR, Description Structure, Tag Allocation, Hashtag Indexing, and Engagement Velocity.
   - Direct feedback and actionable steps to achieve an `A+` grade.

4. **Viral Trend Hunter & Story Continuity Engine**:
   - Top-ranked viral trends in ancient history, forbidden archaeology, and lost technology.
   - Narrative continuity generator for `Marrow`'s multi-part episodic journey.
   - One-click deployment of production-grade 3-scene prompts into NexusFlow `Prompt.txt`!

5. **Direct YouTube Studio Publishing Bridge**:
   - Dual-mode bridge: live HTTP or resilient atomic disk queue into YouTube Uploader.
   - One-click queuing and automated background publishing.

## Quick Start (CLI)

```bash
# View complete ecosystem status
node cli.js status

# Inspect channel positioning & strategy
node cli.js channel

# Generate full algorithmic SEO package
node cli.js seo

# Audit video metadata with 0-100 score
node cli.js audit

# Discover top viral trends to grow the channel
node cli.js trends

# Generate the next video concept & NexusFlow prompt
node cli.js next-video 1

# Deploy the prompt directly to NexusFlow Prompt.txt
node cli.js apply-prompt 1

# Queue video with full SEO package for upload
node cli.js queue

# Autonomous end-to-end pipeline (Discover -> SEO -> Audit -> Queue)
node cli.js full-cycle
```

## MCP Server Integration

The suite includes a native JSON-RPC Model Context Protocol (MCP) server located at `mcp/server.js`.
Tools include:
- `youtube_seo_status`
- `youtube_seo_channel_profile`
- `youtube_seo_generate_package`
- `youtube_seo_audit_package`
- `youtube_seo_get_trends`
- `youtube_seo_get_next_prompt`
- `youtube_seo_deploy_next_prompt`
- `youtube_seo_queue_video`
- `youtube_seo_full_cycle`

To install into Antigravity, run:
```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```
