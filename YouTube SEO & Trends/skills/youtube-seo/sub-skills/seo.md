# Video SEO Optimization Sub-Skill

This sub-skill synthesizes search, browse, and suggested-feed optimized metadata packages for videos generated by NexusFlow.

## Algorithmic Principles

1. **Title Architecture**:
   - **Browse / Suggested Feed**: Focuses on curiosity gap and high emotion (`He Found Something Under Alexandria... 💀 #Shorts`).
   - **Search / Intent SERP**: Front-loads target keyword in first 40 characters (`The Lost Mechanism of Archimedes Found Under Alexandria`).
   - **Hybrid High-Conversion**: Combines curiosity hook with bracketed keyword context (`Archaeologists Found THIS Under Alexandria... (Archimedes Mechanism)`).
   - **Ultra-Shorts Mobile**: Less than 45 characters to avoid mobile feed truncation.

2. **Description Architecture**:
   - **Line 1-2**: High-impact synopsis placed before the "Show More" fold (< 150 characters).
   - **Lore & Story**: Cinematic background narrative reflecting the video scene.
   - **Dialogue**: Quoting characters to enrich semantic keyword density.
   - **Timestamps / Pacing**: 00:00 scene milestones even for 24-second Shorts to trigger YouTube key moments.
   - **Engagement Velocity Question**: Provocative pinned comment prompt to spike comment count (a #1 ranking factor).
   - **Schema.org VideoObject**: Structured JSON-LD markup for Google AI Overviews and Google Video SERP indexing.

3. **Tags Architecture**:
   - Strictly below 500 characters.
   - Tiered distribution:
     1. Brand & Character Tags (Bones of Empires, Marrow)
     2. Broad History Tags (Ancient History, Archaeology, Roman Empire)
     3. Niche Visual Tags (3D CGI, Animation, Cinematic)
     4. Specific Topic Tags (Alexandria Cistern, Archimedes Mechanism)
     5. Long-Tail Search Queries (what was buried under alexandria)
     6. Format Tags (Shorts, YouTube Shorts)

4. **Hashtag Matrix**:
   - 3 primary display hashtags (`#Shorts #History #BonesOfEmpires`).
   - Extended list for deep search crawling.
