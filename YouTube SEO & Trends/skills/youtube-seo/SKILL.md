# YouTube SEO With Antigravity

The comprehensive AI-powered YouTube SEO engine, channel strategist, viral trend hunter, and publishing suite designed natively for Google Antigravity and NexusFlow.

## Core Capabilities

1. **Channel Management & Health**:
   - YouTube Studio authentication verification (Session health, channel handle `@BonesOfEmpires`, profile credentials).
   - Niche positioning, content pillars, protagonist mascot lore (`Marrow`), and competitive benchmarks.
   - Growth checklist for long-term algorithmic channel authority.

2. **Full Algorithmic SEO Engine**:
   - **4 Distinct Title Variants**:
     - *Browse / Suggested Feed* (Curiosity gap, emotional trigger, mystery).
     - *Search / SERP* (High search volume keywords front-loaded in first 40 chars).
     - *Hybrid High-Conversion* (Curiosity hook + bracketed keyword context).
     - *Ultra-Shorts Mobile* (< 45 chars for vertical feeds).
   - **Structured Description Architecture**:
     - Above-the-fold hook (< 150 chars before "Show more").
     - Narrative lore & dialogue quotes from NexusFlow prompts.
     - Scene timestamps & pacing markers.
     - Provocative discussion question pinned to stimulate comment velocity.
     - Calls to Action & playlist/channel links.
     - VideoObject Schema.org JSON-LD for Google Search & AI Overviews.
   - **500-Character Tag Matrix**:
     - Brand tags, broad historical categories, mid-tail topics, and long-tail query phrases strictly within the 500-char YouTube limit.
   - **Hashtag Matrix**:
     - 3 primary above-title hashtags (`#Shorts #History #BonesOfEmpires`) plus 10 extended indexing hashtags.

3. **Algorithmic SEO Quality Scorecard (0-100 pts)**:
   - Evaluates title CTR potential, keyword front-loading, description depth, tag saturation, hashtag indexing, and retention triggers.
   - Generates actionable recommendations to reach an `A+` grade.

4. **Viral Trend Hunter & Story Continuity Engine**:
   - Curated ranking of viral historical, archaeological, and ancient technology topics with search volume tiers, RPM ratings, and virality scores.
   - Continuity Story Generator continuing from previous video cliffhangers (e.g. Marrow stepping through the Alexandria vortex portal).
   - Production-Grade 3-Scene Prompt Generator that outputs camera directives, lenses, audio beds, character locks, and timing ready for NexusFlow `Prompt.txt`.

5. **Direct Publishing & Queue Bridge**:
   - Seamless bridge to YouTube Studio Uploader (live HTTP or resilient atomic disk queue).
   - One-click queuing and optional auto-upload.

## Command Reference

### CLI Usage
```bash
# Holistic System & Channel Status
node cli.js status

# Channel Strategy & Competitor Benchmarks
node cli.js channel

# Generate Algorithmic SEO Package
node cli.js seo

# Run 0-100 SEO Quality Audit
node cli.js audit

# Discover Top Viral Trends
node cli.js trends

# Generate Next Video Concept & NexusFlow Prompt
node cli.js next-video 1

# Deploy Prompt Directly to NexusFlow Prompt.txt
node cli.js apply-prompt 1

# Queue Video with Full SEO Package
node cli.js queue

# Autonomous End-to-End Pipeline
node cli.js full-cycle
```

## MCP Server Tools

The suite exposes a full JSON-RPC MCP server (`mcp/server.js`) with the following tools:
- `youtube_seo_status`: Complete system, channel, video, and queue status.
- `youtube_seo_channel_profile`: Detailed channel strategy, niche pillars, and competitors.
- `youtube_seo_generate_package`: Synthesizes 4 titles, description, tags, hashtags, and schema.
- `youtube_seo_audit_package`: Runs 0-100 algorithmic SEO quality audit.
- `youtube_seo_get_trends`: Lists ranked viral trend ideas with virality scores.
- `youtube_seo_get_next_prompt`: Generates continuity story & 3-scene prompt.
- `youtube_seo_deploy_next_prompt`: Writes prompt directly to NexusFlow `Prompt.txt`.
- `youtube_seo_queue_video`: Adds video with complete SEO metadata to YouTube queue.
- `youtube_seo_full_cycle`: Runs autonomous end-to-end pipeline.
